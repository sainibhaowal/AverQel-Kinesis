## 1. Ethical Standards, Anti-Piracy and Privacy Policy

* **Zero Piracy and Original Integrity**: AverQel Kinesis contains no cracked, pirated, or unauthorized proprietary code, assets, or weights. All code within this repository is either originally authored by AverQel contributors or integrated from verified, permissive open-source upstream projects.
* **No Unauthorized Scraping or Secret Exfiltration**: The platform does not incorporate private, leaked, or confidential corporate intellectual property.
* **Local-First Privacy Guarantee**: AverQel Kinesis operates on an air-gapped, zero-telemetry local paradigm. No user code, session conversations, goal trees, or terminal streams are collected, monitored, or transmitted to AverQel contributors or any external tracking servers.
* **User-Authorized Model Access**: Foundation model APIs (OpenAI, Anthropic, Google, Ollama) are connected solely through official SDK interfaces using the user's own explicitly supplied API keys or local runtimes.
